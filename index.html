clasp-runner

About

clasp-runner is a private tool that runs the owner's own Google Apps Script projects from the owner's own computers. It is not offered to anyone else. There is no sign-up and there are no other users.

Privacy policy

  • Who uses it: only the owner of this page, on the owner's own Google account.
  • Google data it uses: the owner's own Google Sheets and Google Drive files, the owner's email address, and sending email alerts to the owner.
  • How the data is used: only to run the owner's own scripts.
  • Where the data goes: it stays in the owner's Google account and on the owner's computers. It is not sold, shared, or sent to anyone else.
  • Outside websites: the scripts read public web pages, such as prices. No Google user data is sent to them.
  • Contact: through this GitHub account.
